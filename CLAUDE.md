# Mediate: rules for agents

*Where does an agent start, and what must it read before it writes? For an agent.*

Read `README.md` and `CONTRIBUTING.md` first.

Before you create or change any `.md` file, `@moduledoc`, `@doc`, or comment, read `docs/writing.md` and follow its steps. Run its gate over every document you changed, and quote the output in the commit message.
