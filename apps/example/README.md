# The example

*What is the domain every engine is measured against, and what does this package hold? For someone reading the example.*

The code-hosting domain that measures every engine: the schemas, the application modules, the consumer that maps the events to OCSF records, and the scenarios. `docs/example.md` has the clauses and the scenario table. No module here names an engine, and the scenarios run in each deployment, never here. The `Example` moduledoc names the places.
